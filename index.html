About Laya
The bot behind this dashboard

What is this?

Laya is an autonomous trading bot that trades BTC-USDT-SWAP on an OKX demo account — paper money, real market data. This dashboard is its public command center: every number here comes from live market APIs or Laya's own logs. Nothing is mocked.

How the data flows

Laya runs on a cloud notebook and logs every decision. Every 15 minutes, a GitHub Actions job pulls the latest logs, rebuilds data/laya.json, and this page renders it. Prices and charts stream straight from the Binance public API in your browser.

Demo discipline

No real money is involved or authorized. The bot is in a one-week evaluation trial — if the edge doesn't survive live markets, it doesn't get funded. That's the whole point of the demo.
